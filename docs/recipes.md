# Рецепты

## Импорт плова

Миграция `20261120120000_vetdietolog_pilaf_recipe` добавляет один общий рецепт
[«Плов» для взрослых собак](https://vetdietolog.ru/recipes/dogs/dog-pilaf).
Источник проверен 20 ноября 2026 года. Royal Canin и другие примеры не добавляются.

Используется существующий `Product` с типом `RECIPE`, владельцем
`bootstrap-admin` и `isShared = true`. КБЖУ хранятся в полях продукта;
сырая клетчатка (`CFi`), зола (`CAs`) и влага (`MO`) — в `ProductNutrient`.
Импорт учитывает единицы существующего справочника. Неопубликованные нутриенты
не создаются и не подменяются подтверждёнными нулями.

Поля `recipeInstructions` и `recipeNotes` сохраняют порядок приготовления
и условия применения. Они необязательны и не меняют существующие продукты.
Основа в 100 г означает единицу пищевой ценности, а не выход готовой партии.
Расчётных ингредиентов, дозировки добавки и предполагаемой массы блюда нет.

Повторный запуск не перезаписывает рецепт, его ручные изменения, архивное
состояние или мягкое удаление. Записи с тем же источником также не дублируются.
Нет изменений пользователей, их паролей, продуктов, расчётов и рационов.
Старые миграции не редактируются. Отсутствие необходимых справочных нутриентов
вызывает явную ошибку с откатом новой миграции вместо неполного импорта.

## Согласованные требования к редактору

Следующие возможности ещё не реализованы этой миграцией:

- Отдельная таблица рецептов, создание, редактирование и мягкое удаление.
- Личный рецепт принадлежит диетологу; админ видит все, рецепты админа общие.
- Рецепт состоит только из продуктов, без вложенных рецептов, и добавляется в рацион.
- Состав рассчитывается по ингредиентам и массе готового блюда. Массу можно
  изменить; её начальное значение при наличии ингредиентов — сумма их масс.
- КБЖУ и нутриенты на 100 г можно ввести вручную даже без ингредиентов.
- Изменение ингредиентов после ручных правок требует подтверждения: затем
  пересчитываются все значения. Отмена сохраняет прежний состав.
- «Сбросить» отменяет ручные правки и берёт актуальный состав продуктов;
  без ингредиентов обнуляет значения. Обновление каталога само рецепт не меняет.
- В рацион и экспорт попадает итоговый состав. Сохранённые рационы не меняются
  при редактировании рецепта.
- Печать содержит ингредиенты с граммовками, массу готового блюда, приготовление
  и КБЖУ, без полной таблицы нутриентов.

Сейчас миграция подготавливает данные, а не полноценный редактор рецептов
или отображение новых текстовых полей в интерфейсе.

## Проверка

`npm run test:recipe-migration` проверяет состав и безопасность миграции.
Для проверки SQL на PostgreSQL требуется `TEST_DATABASE_URL` пустой локальной
базы с именем, заканчивающимся на `_test`. Тест никогда не очищает существующую базу.
