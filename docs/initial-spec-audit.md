# Проверка первоначального ТЗ

20 ноября 2026 года, по локальному коду после реализации редактора рецептов.
Это сверка реализации; коммит и публикация согласованы пользователем.
Фактический выпуск проверяется по маркеру версии и состоянию контейнеров на VPS.
Сверен большой список пожеланий к расчётам, формулам, рецептам, Excel и
разделу «Полезное», с учётом последующих решений пользователя.

## Выполнено

| Требование | Результат |
| --- | --- |
| Реестр рецептов, создание, редактирование, удаление | `/recipes`, адаптивная форма, мягкое удаление. Проверены браузер и API. |
| Продукты и добавки, без вложенных рецептов | Проверка и в селекте, и на сервере; самоссылки и повторы запрещены. |
| Ручные КБЖУ/нутриенты, с ингредиентами или без | Сброс к актуальным источникам либо нулям. Влага — нутриент MO, считается как остальные. |
| Приготовление и печать | Поля приготовления/примечаний; печать масс, выхода, КБЖУ, без полного списка нутриентов. |
| Ролевая модель рецепта | Общие от админа, личные диетолога; админ видит все. История — владельцу/админу. |
| Смена типа, версии, восстановление | ProductVersion с bus_begin/bus_end, атомарный Save, восстановление новой версией. Старые рационы сохраняются. |
| Поиск нутриентов в продукте | Поиск имени/кода над составом. |
| Все нутриенты рациона в Excel, включая сырую клетчатку | Заголовки шаблона и нутриенты сохранённых строк. Реальный API-тест CFi и unit-тесты дополнительных нутриентов/формул книги проходят. |
| Убранная строка рациона не попадает в Excel | Проверено через API. Удаление самого продукта из каталога, наоборот, сохраняет ранее добавленную строку рациона. |
| Единственный импортируемый рецепт — «Плов» | Миграция 20261120120000, ручной опубликованный состав, без придуманных граммовок ингредиентов. |
| Покупки скрыть | Убраны из общей и мобильной навигации; данные и старый адрес `/invoices` сохранены. |

## Расчёты и формулы: новый этап

Реализованы локально после дополнительного grill-me; текущий договор и
проверки описаны в `docs/formulas.md`.

| Требование | Результат |
| --- | --- |
| Ошибка пустой лактации и разные формы | Одна форма для всех точек входа. Обязательны только зависимости выбранного шаблона. |
| Беременность | Формулы и ручной выбор фазы сохранены. Неделя полностью исключена по последнему решению. |
| Создание/редактирование формулы | Заменено закрытым каталогом. Запрещено всем через UI и API; математическая структура неизменна. |
| Редактирование численных коэффициентов | Все литералы выражения, включая степень; только в этом расчёте, со сбросом и снимком значений. |
| Сохранение слева и уведомление | Общая форма, Shared-уведомление. |
| Клетчатка в верхних показателях | CFi, в граммах в сутки, с отметкой неполных данных. |
| Имена и дубли | Backfill; уникальный активный нормализованный name в пределах владельца, включая конкурентные запросы. |
| Удаление в таблицах | В общей истории и в расчётах клиента, мягкое удаление. |
| Периоды и сохранность рационов | bus_begin/bus_end у Calculation/Ration, снимок формулы; удалённый расчёт сохраняет старые связи, исключён из нового выбора. |
| Виды | AnimalSpecies и speciesCodes; одинаковая фильтрация/проверка в UI и API. Новые шаблоны добавляются обновлением, не редактором. |
| Единое название | В рабочих формах, таблицах и сообщениях — «Формула». Внутренние исторические Module/ModuleFormulaVersion не переименовывались. |

## Отложено или заменено

- «Полезное», админские лонгриды, редактор, публичный доступ и SEO намеренно
  отложены. Пока «Справка» не переименована; подробности в TODO.md.
- Royal Canin заменён одним рецептом по ссылке vetdietolog.ru. Другие рецепты
  не нужно добавлять как «недостающую» работу.
- Скрытие параметров самцам заменено поздним решением дать все поля и оставить
  выбор диетологу. Фильтрация формул по виду питомца всё ещё требуется.

## Осталось

«Полезное», лонгриды и SEO — отдельный отложенный этап. Персональные выражения,
редактор формул и неделя беременности не являются долгом: эти требования
явно отменены. Коммит и деплой текущей реализации согласованы пользователем
20 ноября 2026 года.
