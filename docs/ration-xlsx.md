# Выгрузка рациона

Кнопка «Выгрузить в Excel» возвращает самостоятельную расчётную книгу:

- «Рацион»: порции, доли массы, цены, состав каждого продукта на 100 г и его вклад за период; итоги за период, в среднем за сутки, на 100 г рациона и на 100 г сухого вещества.
- «Нутриенты»: суточные нормы, факт, процент выполнения, допуск и полнота данных.
- «Состав продуктов»: исходные значения, нормализованные к 100 г, и пустые поля цен в руб/кг. Цены в БД не хранятся.

Состав включает обязательные нутриенты исходного шаблона, нутриенты продуктов (в том числе отключённых, чтобы их можно было включить в Excel) и нормы привязанного расчёта. Единицы остаются такими же, как в каталоге; автоматического перевода МЕ витаминов в массу нет. Справочные формы витаминов не экспортируются.

Жёлтые ячейки — входные данные. Изменение количества, граммов в мере, включённости, состава, цены, нормы или допуска пересчитывает связанные результаты. Масса меры сохраняет соотношение граммов и количества на момент выгрузки, даже если справочник мер менялся. Количество дней — 1 для суточного и 7 для недельного рациона; недельные суточные показатели делятся на 7, а не на число заполненных дней.

Пустой состав отличается от известного нуля: в итогах видна известная часть и число позиций без данных. Неизвестная влага блокирует расчёт сухого вещества, пустая цена — полную стоимость. Нулевые порции и отключённые позиции не участвуют ни в суммах, ни в оценке полноты. Нормы берутся из расчёта питомца, а не из статических примеров исходной таблицы. Для БЖУ приоритет имеют поля calculation.protein/fat/carbs, как у верхних виджетов рациона, а не старые дубли в CalculationNutrient. Допуск — настройка сравнения, не токсикологический предел.

Формулы используют обычные функции Excel без внешних связей и макросов. Значения сохраняются без округления, отображение — до восьми десятичных знаков. Редактирование файла не изменяет данные сайта. Для добавления новых продуктов используйте сайт и повторную выгрузку.

## Проверка

`npm run test:rations` проверяет структуру, значения, единицы и сохранение XLSX.

`XLSX_RECALC_COMMAND=/path/to/soffice npm run test:rations` дополнительно открывает и пересчитывает 16 временных книг в LibreOffice, проверяя изменения порций, мер, включённости, состава, цен, норм, допуска, пустые и недельные рационы, неизвестную/нулевую влагу и малые дозировки. Этот тест не требует БД и не меняет пользовательские рационы. Без переменной интеграционная проверка помечается пропущенной. Проверка LibreOffice не заменяет проверку в Microsoft Excel.
